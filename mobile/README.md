# AutoSense Flutter client

See the [project setup guide](../README.md) for API startup, device addresses,
tests and target-platform requirements. The browser uses a clearly labelled demo.
Native BLE and Wi-Fi ELM/CAN readers are experimental and untested on hardware.
The live dashboard includes 10-second acceleration-power recording; its estimates
are not dyno results. History and run data are session-only.
